# 📘 Student Management System (C++)

A simple **menu-driven Student Management System** developed in **C++** that stores student records using either a **TXT file**. This project is suitable for **college assignments, lab work, and beginner-level projects**.

---

## ✨ Features

* Add student records
* Display all student records
* Persistent storage using files
* Menu-driven console interface
* Two storage options:

  * TXT file (basic)
 

---

## 🛠️ Technologies Used

* Language: **C++**
* File Handling: `fstream`

---

## 📂 Project Structure

```
Student-Management-System/
│
├── txt_version.cpp        # C++ code using TXT file
├── students.txt           # Data file for TXT version
├── README.md              # Project documentation
```

---

## 🧾 TXT File Version

### 📄 Data Format (`students.txt`)

```
1 John 20 CSE
2 Alice 19 ECE
```

### ▶️ How It Works

* Each line represents one student
* Data is stored in the order:

  * ID, Name, Age, Course

### ✅ Advantages

* Very simple
* No external libraries
* Ideal for exams and viva
