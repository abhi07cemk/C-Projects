# 💻 C++ Projects Collection

This repository contains a collection of **console-based C++ projects** developed to practice and strengthen core C++ programming concepts such as control structures, functions, file handling, and logic building.

---

## 📂 Projects Included

### 🧮 Calculator
- Performs basic arithmetic operations
- Uses conditional logic and user input
- File: `calculator.cpp`

---

### 🔐 Login System
- Simple authentication logic
- Demonstrates string handling and conditions
- File: `login.cpp`

---

### 📅 Calendar Application
- Displays a formatted calendar for a given month and year
- Handles leap years and day calculations
- Uses mathematical date logic (Zeller’s Congruence)
- File: `calender.cpp`

---

### 📚 Library Management System
- Manages basic library operations
- Demonstrates structured program design
- File: `library.cpp`

---

### 📝 Billing System
- Generates bills based on user input
- Demonstrates calculations and formatted output
- File: `billing.cpp`

---

### 🧠 Quiz Application
- Simple quiz game
- Uses conditions, loops, and scoring logic
- File: `quiz.cpp`

---

## 🧠 Concepts Used

- C++ basics and syntax
- Conditional statements (`if-else`, `switch`)
- Loops (`for`, `while`)
- Functions
- Arrays and strings
- Modular arithmetic
- Console input/output
- File handling (where applicable)
